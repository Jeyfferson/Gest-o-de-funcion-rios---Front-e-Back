# 🚀 Gestão de Funcionários — Full Stack App

Um sistema web completo (CRUD) desenvolvido para fins de estudo e prática de integração entre **Front-end** e **Back-end**. A aplicação permite cadastrar, listar, atualizar e remover registros de funcionários em tempo real através de uma API RESTful.

---

## 📌 Sobre o Projeto

Este projeto foi construído com o objetivo de fixar os conceitos fundamentais do desenvolvimento web Full Stack, cobrindo desde a criação da interface do usuário até a persistência de dados no banco de dados através de uma API local.

### 🛠️ Tecnologias Utilizadas

#### **Front-end**
* **HTML5** — Estruturação semântica da página.
* **CSS3** — Estilização moderna com conceito *Glassmorphism*, layout responsivo (Flexbox/Grid) e fonte *Plus Jakarta Sans*.
* **JavaScript (ES6+)** — Manipulação do DOM, manipulação de eventos e requisições assíncronas com `fetch` e `async/await`.

#### **Back-end**
* **Node.js** com **Express** — Criação das rotas da API REST (`GET`, `POST`, `PUT`, `DELETE`).
* **Banco de Dados** — Persistência e gerenciamento das informações dos funcionários.

---

## 🧠 Aprendizados e Desafios

Durante o desenvolvimento desta aplicação, foram praticados e consolidados diversos conhecimentos técnicos:

1. **Operações CRUD Completas:** Compreensão prática de como mapear ações da interface para os verbos HTTP correspondentes (`Create`, `Read`, `Update`, `Delete`).
2. **Consumo de APIs Assíncronas:** Uso do `fetch` para comunicação com o servidor e tratamento de dados com `async/await` e depuração em blocos `try/catch`.
3. **Gerenciamento do Estado da Interface:** Dinâmica de alternância de modos no mesmo formulário (modo de inclusão vs. modo de edição) e re-renderização dinâmica de elementos HTML (`<tbody>`).
4. **Resolução de Bugs e Debugging:** Identificação de falhas de fluxo de execução (como *returns* precoces) e sincronização dos identificadores (`id`) entre HTML e scripts JavaScript.
